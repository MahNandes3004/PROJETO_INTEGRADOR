SOBRE O PROJETO

Aprender também pode ser interativo.

Este site foi criado para apresentar conceitos de Física e Eletrônica de uma forma visual, simples e acessível.

Ao longo do projeto você poderá experimentar virtualmente diferentes fenômenos relacionados às cores, à luz e aos LEDs.

A proposta é aproximar a teoria da prática, permitindo que o visitante não apenas leia, mas também interaja com os conceitos.

💡
Você sabia?

Isaac Newton utilizou um prisma para estudar a decomposição da luz branca nas cores do espectro. O Disco de Newton funciona como uma demonstração visual da recombinação dessas cores.

O que é o Disco de Newton?

Clique para virar →
01

Resposta

É um disco dividido em várias cores do espectro visível que, ao girar rapidamente, produz a sensação de uma cor clara, próxima do branco.

02
💡

O que é um LED RGB?

Clique para virar →
02

Resposta

É um LED que possui três componentes principais: vermelho, verde e azul. A combinação dessas três cores permite produzir várias outras cores.

03
✨

O que é Fade In?

Clique para virar →
03

Resposta

É um efeito em que a intensidade luminosa aumenta gradualmente, fazendo o LED aparecer ou ficar progressivamente mais brilhante.

04
🔬

O que é PWM?

Clique para virar →
04

Resposta

PWM é uma técnica que controla a quantidade média de energia entregue a um dispositivo, sendo muito utilizada para controlar o brilho de LEDs.

05
🎨

Quais são as cores do RGB?

Clique para virar →
05

Resposta

RGB significa Red (vermelho), Green (verde) e Blue (azul). Essas três cores formam a base da mistura aditiva de luz.

06
⚡

O que é Fade Out?

Clique para virar →
06

Resposta

É o processo inverso do Fade In: a intensidade da luz diminui gradualmente até o LED ficar muito fraco ou apagado.
